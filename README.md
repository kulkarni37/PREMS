## 📖 Overview

**PRMES (Project Review Management & Evaluation System)** is a centralized web application designed to simplify and automate the management of final-year engineering projects.

The platform enables students, guides, coordinators, and administrators to collaborate efficiently through a secure and structured workflow—from project registration to final evaluation.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/PRMES.git
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
pip install -r requirements.txt
python app.py
```
